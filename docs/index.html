Blockchain storage engine surviving 2-of-6 node failures — Java, Reed-Solomon (4+2) erasure coding

View source on GitHub ↗
🟡 This page runs a real Reed-Solomon (4 data + 2 parity) GF(256) erasure codec written in JavaScript — the same systematic-Vandermonde-matrix construction as src/ReedSolomonHelper.java in this repo — so encoding and reconstruction below are genuine, not simulated. Encode a message, "kill" any 2 of the 6 storage nodes, and reconstruct it byte-for-byte in your browser.

Encode & reconstruct

Enter a short message (this is what a block's data field would hold), click Encode to split it across 4 data + 2 parity shards, then click up to 2 nodes to mark them as failed and hit Reconstruct.
