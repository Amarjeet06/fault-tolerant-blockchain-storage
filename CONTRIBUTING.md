# Contributing to CS4545 Blockchain Project

## Development Setup

1. Clone the repository
2. Ensure Java 8+ is installed
3. Build the project using the provided scripts

## Code Style

- Follow Java naming conventions
- Use meaningful variable and method names
- Add comments for complex logic
- Keep methods focused and single-purpose

## Project Structure

- `src/` - Main source code
- `data/` - Data files (CSV, etc.)
- `docs/` - Documentation and images
- `scripts/` - Build and run scripts
- `JavaReedSolomon-master/` - External library (do not modify)

## Building

See `README.md` for build instructions.

## Testing

Add tests for new features and ensure existing tests pass.

## Package Organization

- Files in `com.backblaze.erasure` package should remain in that package
- Main application files are in the default package
- Keep package structure consistent
